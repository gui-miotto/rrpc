# Introduction

Please create a website for a paper club.

The website should be a static website for github.

The club is called "Rhine Robotics Paper Club"

The "reference_material" directory contains the color pallete that should be used and other pieces for visual identity reference. This directory not a part of the project and will be deleted.

# Website contents

- A quick intro about what this page is about - including a hook to the discord channel
- A list of scheduled and previous meetings
- A small paragraph about myself
- A "With the support of" part at the botom of the page (see logos in reference_materia/flyer)

Feel free to add anything that I might have missed.

The meeting description should contain:
    - The edition of the event (i.e. meeting number)
    - Location and time
    - Link for signing up (luma.com)
    - The list of papers that will be presented, including:
        - paper name
        - link for downloading the paper
        - presenter's name
    (Expect each meeting to have 1 to 3 papers)

# Implementation remarks

If possible, make all text content of the website availabe in yaml files. Most importantly, the meeting descriptions. Adding a new yaml file (or an entry to a yaml file) should be enought to add a new event to the page.
